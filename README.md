# 🛒 BazarDor (বাজার দর)

**BazarDor (বাজার দর)** is a modern, responsive full-stack web application designed to help users track, compare, and monitor daily market prices of essential commodities and daily necessities in real-time. 

---

## ✨ Features

- 📊 **Real-Time Price Tracking:** Keep an eye on daily fluctuations and price trends of essential market items.
- 🗂️ **Category-Based Browsing:** Easily filter and browse products by categories (e.g., vegetables, rice, fish, meat, spices, etc.).
- 🔍 **Smart Sorting & Search:** Sort products by price or search items instantly.
- 🔐 **Secure Authentication:** Built-in secure user authentication (Email/Password & Social logins) powered by **Better Auth**.
- 📱 **Responsive Design:** Fully responsive and optimized layout for both mobile and desktop devices.
- 👤 **Profile Management:** Users can manage their personal profiles and saved preferences securely.

---

## 🛠️ Tech Stack

- **Frontend & Backend:** [Next.js (App Router)](https://nextjs.org/) / React
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Database:** MongoDB
- **Authentication:** Better Auth
